# montgomery-county-311-etl
End-to-end ETL pipeline for Montgomery County 311 service requests using Databricks and Medallion Architecture. 
Transform Montgomery County, Maryland's 311 service request data into reliable datasets that support operational analysis and help identify opportunities to improve public service delivery.

# Analysis Goals
1. Service Demand: Analyze the total number of service requests and identify the most frequently requested services.

2. Department Workload: Determine which Montgomery County departments receive the highest volume of service requests.

3. Resolution Performance: Calculate how long it takes to resolve service requests and compare resolution times across departments.

4. Request Status: Analyze the number and percentage of open versus closed service requests.

5. SLA Compliance: Determine the percentage of service requests completed within their service-level targets and compare compliance across departments.

6. Geographic Demand: Identify which cities and ZIP codes generate the highest number of service requests.

7. Request Trends: Analyze service request volume over time to identify daily, monthly, and seasonal patterns.
